# Поддержка аксонного исследования в Rdk

Аксонная программа использует штатный scheduler, связи свойств и сохранение
модели. [Постановка и протоколы](../../Docs/StructTrain/AxoneTimeLearner/README.ru.md)
хранятся в корневом репозитории.

NNeuronAxoneTimeLearner не должен повторно рассчитывать вложенные участки.
При перестройке сохраняются внешние порты и проверяются все затронутые
получатели. Сохранение структуры и параметров не объявляется checkpoint
динамики. Проверка проводится на реальных компонентах и после загрузки.

Новый общий механизм Rdk вводится только при установленной потребности.
Этот документ не изменяет исполняемую логику Rdk. Локально разрешено
редактирование, сервер исполняемой приёмки — .15.
